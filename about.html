About EduPredict

This project aims to predict the academic performance of a student based on various input factors such as study hours, attendance, previous scores, assignments, and lifestyle habits like sleep and extracurricular activities.

Using a combination of HTML, CSS, and vanilla JavaScript, we have built a responsive frontend application that provides real-time feedback and personalized suggestions to help students improve their academic trajectory.

Technologies Used

  • HTML5
  • CSS3
  • JavaScript (Vanilla)
  • Chart.js
  • Google Fonts
  • Font Awesome

Future Scope

  • Integrate Machine Learning Model (Python + Flask / Django API)
  • Store Data in a Database
  • User Authentication and Profiles
  • Admin Dashboard for Educators
  • Exportable Performance Reports
